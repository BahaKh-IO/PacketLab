# How to start in VS Code

1. Create the GitHub repo `packetlab` (public, with a README) and clone it.
2. Copy into the repo root:
   - `CLAUDE.md` (root)
   - `docs/PLAN.md`, `docs/PacketLab_Objectif1.pdf`
3. Download `PacketLab_Description_Detaillee.md` from the claude.ai project "Web Project" and put it in `docs/`.
4. Open the repo folder in VS Code, open Claude Code, and paste the first prompt below.

## First prompt

```
Read CLAUDE.md, docs/PLAN.md and docs/PacketLab_Description_Detaillee.md.
We are at "Today, Step 2" of the plan. First check that CLAUDE.md is consistent
with the plan and tell me if anything is missing. Then create the folder structure
from the plan and the 7 pages with a shared header and navigation, no logic yet.
Show me your plan before writing files.
```

Then follow prompts 3 to 8 in docs/PLAN.md ("Claude Code prompts for today"), one at a time.
