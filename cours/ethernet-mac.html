1. Le rôle d'Ethernet

Ethernet est la technologie qui fait passer les données d'une machine à une autre sur un même réseau local. Il travaille dans la couche 2 (liaison de données) : il emballe le paquet IP dans une trame, avec les adresses nécessaires pour la livrer sur le câble, puis la couche physique transmet les bits.

Il faut bien distinguer les deux enveloppes : la trame (Ethernet, adresses MAC) ne sert que sur un tronçon ; le paquet (IP, adresses IP) voyage de bout en bout.

2. L'adresse MAC

Chaque carte réseau possède une adresse MAC de 48 bits, écrite en six octets hexadécimaux : AA:AA:AA:00:00:0A.

  • Les trois premiers octets forment l'OUI, l'identifiant du constructeur ;
  • les trois derniers sont attribués par le constructeur à chaque carte.

Une MAC ne contient aucune information de réseau : elle dit qui est la carte, pas où elle se trouve. C'est pour cela qu'on a besoin des adresses IP pour aller d'un réseau à un autre.

L'adresse FF:FF:FF:FF:FF:FF est l'adresse de diffusion : une trame qui la porte en destination est acceptée par toutes les cartes du réseau local.

3. La trame Ethernet

ChampTailleRôle
Préambule8 octetsSynchroniser le récepteur avant la trame.
MAC destination6 octetsCarte qui doit garder la trame.
MAC source6 octetsCarte qui a envoyé la trame.
Type2 octetsCe que transportent les données (par exemple IPv4 ou ARP).
Données46 à 1500 octetsLe paquet IP (complété si trop court).
FCS4 octetsCode CRC pour détecter une erreur de transmission.

Le récepteur recalcule le FCS : si le résultat ne correspond pas, la trame a été abîmée en route et elle est jetée. Ethernet détecte les erreurs, mais ne les répare pas.

4. Qui garde la trame ?

Quand une carte reçoit une trame, elle compare la MAC destination à la sienne :

  • c'est sa MAC, ou la diffusion : elle garde la trame et passe le contenu à la couche du dessus ;
  • sinon : elle l'ignore.

Sur un support partagé (un bus, un concentrateur), toutes les cartes voient passer toutes les trames, et ce tri est la seule chose qui fait que chacune ne garde que les siennes.

5. Partager le support : CSMA/CD

Si deux stations émettent en même temps sur un support partagé, les signaux se mélangent : c'est une collision, et les deux trames sont perdues. Ethernet classique applique la méthode CSMA/CD :

  1. écouter le support et attendre qu'il soit libre ;
  2. émettre ;
  3. surveiller pendant l'émission : si une collision est détectée, arrêter ;
  4. attendre un temps aléatoire, puis réessayer.

Pour qu'une collision soit détectée pendant l'émission, la trame doit durer assez longtemps : c'est l'origine de la taille minimale de 64 octets. Avec des commutateurs en duplex intégral, les collisions disparaissent.

6. Les MAC changent, les IP restent

Exemple : PC-A vers PC-B à travers deux routeurs

À retenir

  • MAC : 48 bits, identifie une carte, ne sert que sur un tronçon.
  • Trame : MAC destination, MAC source, type, données (46 à 1500 octets), FCS.
  • Une carte garde les trames pour sa MAC ou pour FF:FF:FF:FF:FF:FF, et ignore les autres.
  • CSMA/CD : écouter, émettre, détecter, réessayer.
